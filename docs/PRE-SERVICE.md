# Before the service

Run this at the rig before every service. It takes a few minutes. Open
**Devices > Server check**: the "Before the service" block at the top ticks the
first four items for you. Items 5 and 6 are yours.

1. **Audio drivers.** Every driver is running and has had no dropouts lately.
   If one is missing, plug in or switch on the device. Green in the block means good.
2. **Console link.** Each console (CL5, X32) shows as connected. If not, check
   the cable or network and the address under Consoles.
3. **Remotes.** The iPad / web remote and LiveRack Client can reach this
   computer. Open the remote on the iPad and see it load.
4. **Server check.** Nothing says "to look at". Press the fix button on a row
   that does, then **Check again**.
5. **Snapshots.** The right snapshot for this service is loaded. LiveRack can't
   know which one that is, so look at it yourself.
6. **Computer.** Not asleep or locked, and the power plan is right. The Server
   check rows cover this; make sure they are green.

A grey hollow light in the block means LiveRack can't tell (for example, no
remote is turned on). It is never a pass.
